**Finding for your decision (not changed).** A Sorter row's height setting is only a minimum, and the containers hug their content. This has been true since before Stage 1. Stack height ratios therefore divide only the free height beyond each stack's content (in the rows and the preview alike), and top/bottom alignment only shows where a neighbouring cell in the same stack is taller. Making the template fill the row height would make the ratios absolute, but it would change how every saved layout looks.
