The grid geometry is controlled by the user.

CONTENT DOES NOT RESIZE THE GRID.

1. MASTER ROW HEIGHT

3. STACK HEIGHT WEIGHTS

Each container's available height must be divided according to its stacks' saved heightWeight values.

Examples:

One stack:
1.0 = 100% available height.

Three equal stacks:
1 / 1 / 1 = equal thirds.

Three unequal stacks:
1 / 2 / 1 = 25% / 50% / 25%.

Changing a stack weight must redistribute the available height without changing the parent row height.

Content size must not establish a minimum stack height that overrides these ratios.

4. CONTAINER WIDTH WEIGHTS

Preserve the existing proportional container-width system.

Example:

Three containers with width weights 2 / 1 / 1 occupy approximately:

50% / 25% / 25%

of the usable horizontal space, excluding existing gaps and fixed controls.

At narrower or wider viewport widths, including portrait and landscape, the same configured weight relationship must remain.

Do not automatically change container order, counts, or weight ratios based on screen orientation.

5. SPLIT WIDTH WEIGHTS

Within each stack, splits continue dividing available width according to their saved widthWeight values.

Example:

2 / 1 / 1 = approximately 50% / 25% / 25% of the available stack width.

Content must not widen a split or force its siblings to shrink beyond the configured ratio.
