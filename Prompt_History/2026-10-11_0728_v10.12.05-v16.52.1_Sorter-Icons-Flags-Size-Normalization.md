PLATTS PROPOSAL — v10.12.05 SORTER ICONS/FLAGS SIZE NORMALIZATION: FINAL REPORT

Status: implemented and focused-verified. Nothing committed, pushed or deployed.

1. EXISTING ICON TYPES AND CAUSE
- Condo (building) and Attic (ladder): plain emoji text in the cluster. Refrigerant (snowflake, in a span) and Coastal Match (wave): emoji. Crane: emoji. These all follow the split's Font Size (glyph ink is about 1.0 em: 11.3 px at 11, 24.6 at 24, 33.5 at 32).
- Salt Shield: an inline SVG (getSaltShieldIconSvg, 24 x 24 viewBox, shield artwork 16 x 20 units) inside a span, class "w-5 h-5" = a FIXED 20 px box. Labor Warranty: a Lucide file-check icon, class "w-4 h-4" = a FIXED 16 px box.
- Cause: the two SVG flags were fixed-pixel, so they never scaled with Font Size while the emoji did. Measured shield ink was always 13.3 x 16.7 px: it looked small next to condo / attic at 16 px and above (24.6 px at 24, 33.5 at 32) and was actually larger than the emoji at the default 11 px.

2. EXACT CORRECTION (CSS/markup only, Agent/retest.html)
- Salt Shield SVG class "w-5 h-5" -> "srt-flag-svg"; Labor Warranty icon class "w-4 h-4 text-emerald-400" -> "srt-flag-lucide text-emerald-400" (same wrappers, titles, colours, order, conditions).
- New CSS next to the Sorter rules: .srt-flag-svg { width: 1.25em; height: 1.25em; flex: none } and .srt-flag-lucide { width: 1.2em; height: 1.2em; flex: none }. The em is the cell's font size, so one Font Size now scales every flag. The shield artwork fills 2/3 x 5/6 of its box, so a 1.25em box gives ink about 0.83em x 1.04em, i.e. the shield's height matches the emoji's ~1.0em (small optical bump, shield only). No new settings, storage or per-icon controls. The modal badge rendering elsewhere (separate code) is untouched.

3. BEFORE / AFTER (shield ink height next to the emoji ink height, px; harness icons_probe.py)

- Font 32: before 16.7 vs 33.5; after 33.3 vs 33.5.
- Warranty icon box at 24 px: 16 -> 21.6 px (ink about 0.75 of the box, like the shield).
- Infiniguard (blue) shield scales identically.

4. FONT-SIZE SCALING
